## F1 目录扫描与 RAW/JPEG 配对

| 项 | 设计 |
| --- | --- |
| 扫描范围 | 默认仅当前目录;设置可开"包含子目录"(递归,按相对路径归组) |
| 识别格式 | **RAW**: `cr2 cr3 nef nrw arw srf sr2 raf orf rw2 dng pef srw x3f`<br>**JPEG**: `jpg jpeg jpe`<br>**忽略**: `xmp aae thm wav` 等附属文件;`.wuling/` 永远排除;隐藏/系统文件排除 |
| 配对规则 | 同目录 + 主文件名匹配(大小写不敏感;`IMG_1234.CR2` ⇄ `IMG_1234.JPG`);RAW 为主卡,JPEG 为附属预览源 |
| 配对展示 | 卡片显示 `RAW⇄JPG` 徽标;对比模式中可切换看哪一路 |
| 长片名截断 | 保留前 6 后 4 字符,中段 `…` |
| 增量刷新 | `FileSystemWatcher`(防抖 500ms): 新增→追加卡片;删除→移除;改名→重新配对;手动"刷新"重建 |
| 边界 | 同名 RAW 同时存在 `.jpg` 与 `.jpeg` → 优先较大者;无 RAW 的孤立 JPEG 独立成卡;空目录 → 空态页"选择有照片的目录" |
| 验收 | 样例目录(见 `docs/test-fixtures` 计划)配对正确率 100%;10k 文件 < 2s 出首批 |

## F2 目录预览区(快速浏览)

| 项 | 设计 |
| --- | --- |
| 缩略图 | 异步解码 + LRU 双层缓存;JPEG 直解,RAW 提取内嵌预览(02 §6);统一方形裁切 `UniformToFill` |
| 虚拟化 | 水平 `VirtualizingStackPanel`,视口外卡片仅占位;滚动时解码优先级 = 可视 > 邻近 > 其余 |
| 交互 | 单击入/出对比区;双击放大浮层;拖拽到对比区槽位;`Ctrl+滚轮` 缩放 64-256px |
| 过滤 | 全部/未标记/选中/废弃 四态切换,计数入状态栏;过滤不改变标记 |
| 排序 | 文件名自然序(默认)/ 拍摄时间(读 EXIF,失败回退文件 mtime) |
| 验收 | 10k 张滚动掉帧 < 5%;过滤切换 < 100ms |

## F3 对比区与模式(总框架)

| 项 | 设计 |
| --- | --- |
| 槽位 | 1-9,布局自动 1×1/1×2/1×3/2×2/2×3/3×3;槽位内容与模式解耦 |
| 模式切换 | 模式条单选;切换不丢槽位;模式声明 `MinSlots/MaxSlots` 决定可用性 |
| 槽位操作 | [✅][🗑][✕] + 信息条(文件名 + 当前模式摘要行,如 `f/4 1/250 ISO400 EV+0.3`) |
| 摘要行 | 由模式提供(`GetSummary(pair)`),如 EXIF 模式给关键参数,差分给 Δ 值 |
| 放大镜 | 任意槽双击 → 1:1 像素放大浮层(滚轮缩放、空格平移),便于对比锐度 |
| 插件化 | 渲染完全委托模式插件(契约见 04 文档);内置模式同走插件管道 |

## F4 标记与状态机

| 项 | 设计 |
| --- | --- |
| 三态 | `Unmarked / Selected / Rejected`;合法性由 `TagStateMachine` 集中管理 |
| 操作入口 | 槽位按钮、浏览条右键菜单、快捷键(`1-9` 选中 / `Shift+1-9` 废弃 / `0` 清除)、菜单栏 |
| 即时反馈 | 角标+颜色即时更新;对比区槽位边框同步着色(绿/红/灰) |
| 批量 | 槽位多选后批量标记;"清除全部标记"需确认 |
| 防误触 | 废弃标记要求槽位获得过焦点(避免盲按);无确认弹窗,靠"提交确认 + 软删除"兜底 |
| 进度感知 | 状态栏 `128 张 (✅12 🗑3 ⬜113)`;过滤"未标记"帮助收敛 |
| 验收 | 状态机单测覆盖全迁移路径;标记后 1s 内会话落盘 |

## F5 会话保存与恢复

| 项 | 设计 |
| --- | --- |
| 内容 | 标记表、槽位顺序、当前模式、槽位数、UI 偏好(窗口/分栏/缩略图大小) |
| 落盘 | `.wuling/session.json` 原子写(tmp+rename);自动保存防抖 1s + 30s 兜底 |
| 恢复 | 打开目录时若存在会话 → 提示"恢复上次进度?(N 张已标记)";选择恢复则重放标记与槽位 |
| 健壮性 | 按路径键控重放,目录内容变化后仍可恢复;损坏 JSON → 备份并新建 |
| 跨设备 | 会话随目录走(网盘/U 盘同步即迁移);只读目录回退 AppData(02 §9) |
| 验收 | 杀进程重启恢复;10k 目录会话文件 < 2MB、保存 < 200ms |

## F6 对比模式 — 内置四模式(首批实现)

> 均实现插件契约(04 文档),此处定义产品行为。

| 模式 | 槽位 | 内容 |
| --- | --- | --- |
| **JPEG 预览** | 1-9 | 直出 JPEG 显示;RAW+JPEG 对显示 JPEG 路;底部摘要: 尺寸/大小 |
| **RAW 预览** | 1-9 | RAW 内嵌预览提取显示;无预览的格式显示占位;摘要: RAW 格式/内嵌预览尺寸 |
| **EXIF 元数据对比** | 2-9 | 每槽一张关键参数表: 机身/镜头/焦距/光圈/快门/ISO/曝光补偿/对焦模式/拍摄时间;**差异高亮**(字段值不一致处着色);侧栏支持全字段展开与复制 |
| **差分对比** | 2 | 大图两栏;中缝可拖动分割线;可选 **直方图叠加** 与 **RGB 色彩曲线**(SkiaSharp 绘制,ISO/白平衡差异导致的偏色直观可见);摘要: 亮度/对比度 Δ 指标 |

后续批次模式(插件化,分批交付,对应 TODO #8): 同名 JPEG⇄RAW 直比、连拍序列滑动比对、哈希去重建议、自定义 Python 处理预览等。

## F7 提交与照片处置

| 项 | 设计 |
| --- | --- |
| 处置矩阵 | 三类标记各自独立配置: `移动到目录… / 删除 / 不做处理`;默认: 选中=不动,废弃=软删除,未标记=不动 |
| 目标目录 | 每类标记可设独立目标目录;支持 `{原相对路径}` 占位符(递归模式);记入最近使用列表 |
| 提交确认 | 汇总表(动作/张数/目标),不可逆项标红;>50% 且 >100 张删除需键入确认 |
| 执行 | `CommitPlanner` 生成计划 → 校验(冲突/权限/跨卷) → 逐项原子执行 + 事务日志 → 结果报告(成功/失败/跳过),失败可重试 |
| RAW+JPEG 绑定 | 对默认一起处置;拆散需在设置显式开关(防漏选) |
| 完成后 | 会话归档为 `session.completed-{ts}.json`;目录保留 `.wuling` 供还原;提供"还原上次提交"入口;结果报告提供 **清理 .wuling** 收尾动作(01 文档 §2.4): 两级 — "仅清缓存"(删 `cache/`,保留会话/日志/回收站)与"整目录删除"(含 `trash/` = 软删除照片永久销毁,键入 `DELETE` 确认;执行前强制先还原或确认放弃回收站内容,并等待 plugin_io 引用计数归零) |
| 验收 | 模拟中断(杀进程)后续跑/回滚一致;移动/删除结果与计划 100% 一致;整目录删除路径在回收站非空时被拦截或完成显式确认 |

## 非功能需求汇总

| 维度 | 指标 |
| --- | --- |
| 性能 | 10k 张目录: 首屏 < 3s(冷)/< 500ms(热);滚动掉帧 < 5%;模式切换 < 300ms |
| 内存 | 10k 会话 < 500MB 峰值;缩略图缓存按上限封顶 |
| 可靠性 | 崩溃后重开可恢复;提交事务一致;软删除可还原 |
| 平台 | Win10+/macOS 12+/主流 Linux(x64+arm64);行为一致 |
