## 关键决策记录 (ADR 摘要)

| # | 决策点 | 结论 | 理由摘要 |
| --- | --- | --- | --- |
| D1 | GUI 框架 | **Avalonia 11 + .NET 8 (LTS)** | 真正跨平台(Win/macOS/Linux)、成熟 MVVM 生态、Skia 渲染管线与图像处理天然契合。MAUI 不支持 Linux;Electron/Tauri 需要引入 Web 技术栈且大图渲染性能难控;Qt 有商业授权问题。 |
| D2 | MVVM 框架 | CommunityToolkit.Mvvm 8.x | 源生成器减少样板代码,微软官方维护。 |
| D3 | RAW 显示策略 | **优先提取 RAW 内嵌预览 JPEG**,全解码(LibRaw P/Invoke)作为后期增强 | 内嵌预览提取快(毫秒级)、零重依赖,满足"对比选片"而非"精修"的画质需求。 |
| D4 | EXIF 读取 | MetadataExtractor(纯托管) + 可选 ExifTool 进程兜底 | 覆盖 JPEG 与主流 RAW,跨平台无原生依赖。 |
| D5 | Python 插件引擎 | **进程外常驻 Worker + JSON-RPC over stdio**,二进制经临时文件交换 | 崩溃隔离、Python 版本自由(≥3.9)、无 GIL/嵌入式版本绑定问题;大块像素数据走临时文件,控制消息走 stdio。 |
| D6 | 会话持久化 | `<目录>/.wuling/session.json`(只读目录回退 AppData) | 进度随目录走,换机器可续;自动保存防抖。 |
| D7 | 删除策略 | **默认软删除**至 `.wuling/trash/`(含还原清单),可选永久删除/系统回收站(Win) | 可恢复、跨平台行为一致,破坏性操作必须可逆。 |
| D8 | 内置模式与插件 | 内置模式(JPEG/RAW/EXIF/曲线)同样实现插件契约 | "吃自己的狗粮",保证插件接口不退化为二等公民。 |

## 里程碑概览 (详见 02-architecture 第 11 节)

| 里程碑 | 范围 | 出口标准 |
| --- | --- | --- |
| M0 骨架 | Shell + 打开目录 + JPEG 缩略图浏览条 | 万级文件目录可流畅滚动浏览 |
| M1 核心选片 | 对比区(1-9 槽) + 标记 + 会话保存/恢复 + 提交处理 | 完整跑通主工作流闭环 |
| M2 RAW 与元数据 | RAW 内嵌预览 + EXIF 对比 + 直方图/曲线 | CR2/CR3/NEF/ARW/DNG 主流机型可用 |
| M3 插件系统 | 插件契约 + C# 加载器 + Python 引擎 + 差分对比插件 | 双语言宿主加载/渲染可运行 |
| M4 打磨 | 回收站/还原、递归扫描、i18n、安装包分发 | 三平台安装包与冒烟矩阵通过 |
